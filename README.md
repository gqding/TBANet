## Getting Started
### 1. Installation
You can install the envs from yml file by
```
conda env create -f environment.yml
```

### 2. Datasets

The download links of datasets can be found in [Datasets]().

### 3. Run
After the preparation, you can run the script by 
```sh
sh run_train_eval.sh
```
